# ATS Project Instructions

## General Rules

- Preserve all existing functionality.
- Do not rewrite the project from scratch.
- Make the smallest necessary changes.
- Inspect code before modifying it.
- Work on one module at a time.
- Do not modify unrelated modules.

## Backend

- Do not modify backend code unless explicitly requested.
- Do not change existing API workflows.

## Google Sheets / Apps Script

- Preserve the existing Google Sheets workflow.
- Do not change Apps Script behavior unless explicitly requested.
- Do not remove existing data operations.

## Frontend

Preserve:
- Candidate CRUD
- Filtering
- Pagination
- Modals
- Search
- Interview scheduling
- Trackers
- Resume links
- Existing navigation
- Existing JavaScript functionality

## 3D Conversion

When converting the ATS to 3D:

- Add the 3D experience without destroying existing functionality.
- Do not replace working functionality unnecessarily.
- Do not convert the entire project in one step.
- Work module by module.
- Preserve existing data and API logic.
- Test each module after modification.

## Safety

- Do not expose API keys or credentials.
- Do not commit secrets.
- Do not delete files unless explicitly requested.
